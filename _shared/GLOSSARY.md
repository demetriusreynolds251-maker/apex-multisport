# Glossary
- **PrizePicks line:** the number a player must go over (MORE) or under (LESS).
- **Goblin / Demon / Standard:** easier, harder and normal PrizePicks lines, with different payouts.
- **Power / Flex:** all legs must hit / some misses still pay.
- **Open / close:** first and last blended pre-game line from SportsGameOdds.
- **Before start:** last updated before the listed start time.
- **Backtest:** testing a rule on past games, with nothing bet or posted.
